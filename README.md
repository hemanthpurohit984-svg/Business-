# Business Android App

Starter Android app named **Business** for selling all types of goods/services.

## Included
- Product browsing/search UI
- Categories
- Cart counter
- Cash-on-delivery order flow
- WhatsApp contact to **8667260452**
- Android project structure ready for Android Studio

## Build
Open this folder in Android Studio and let Gradle sync, then choose **Build > Build APK(s)**.

## Next upgrades
